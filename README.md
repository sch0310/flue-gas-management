## 微信提醒配置（Server酱）

### 第一步：注册 Server酱

1. 打开 [sct.ftqq.com](https://sct.ftqq.com) 
2. 点击"登录" - 可以用 GitHub/QQ/微信 登录
3. 登录后，在"发送消息"页面可以看到你的 **SendKey**

### 第二步：配置 SendKey

有两种方式配置：

**方式一：环境变量（推荐）**
```bash
export SERVERCHAN_SEND_KEY="你的SendKey"
```

**方式二：修改代码**
打开 `app.py`，找到 `check_reminders` 函数，将：
```python
send_key = os.environ.get('SERVERCHAN_SEND_KEY', '')
```
改为：
```python
send_key = '你的SendKey'  # 直接填写
```

### 第三步：测试提醒

配置好后，访问：
```
https://webview.e2b.bj10.sandbox.cloudstudio.club/check?x-cs-sandbox-id=0cbe2734e53f44fc9e0294134d1cf31c&x-cs-sandbox-port=5000
```
（将上方地址中的 `/` 改为 `/check`）

如果配置正确，会返回检查结果。

## 定时任务设置

### Linux/Mac 系统（使用 crontab）

每天上午 9:00 自动检查：

```bash
crontab -e
```

添加一行：
```
0 9 * * * curl -s "http://你的服务器地址/check" > /dev/null 2>&1
```

### Windows 系统（使用任务计划程序）

1. 打开"任务计划程序"
2. 创建基本任务
3. 触发器：每天
4. 操作：启动程序
5. 程序：`curl`
6. 参数：`"http://你的服务器地址/check"`

## 使用流程

### 1. 首次使用 - 添加标气记录

- 打开首页，点击"新增标气"
- 选择工厂 → 标气自动联动
- 填写浓度（保留2位小数）
- 选择生产日期
- 提交保存

### 2. 日常使用 - 扫码填写

- 打开首页，点击"扫码填写"
- 用手机扫描二维码
- 填写标气信息并提交

### 3. 查看记录

- 首页自动显示所有标气记录
- 可按工厂/状态筛选
- 显示剩余天数和状态（正常/即将到期/已过期）

### 4. 接收提醒

- 系统每天自动检查
- 标气到期前 45 天，微信收到提醒
- 提醒内容包含：工厂、标气、浓度、生产日期、到期日期、剩余天数

## 技术说明

- **后端**: Python Flask
- **数据库**: SQLite (flue_gas.db)
- **提醒**: Server酱 (微信公众号推送)
- **二维码**: 动态生成，指向表单页面

## 常见问题

**Q: 微信提醒没收到？**
A: 检查 SendKey 是否配置正确，访问 `/check` 接口查看返回结果。

**Q: 如何修改标气信息？**
A: 目前不支持在线编辑，可以删除后重新添加。

**Q: 数据存在哪里？**
A: SQLite 数据库文件 `flue_gas.db`，位于项目目录。

**Q: 如何备份数据？**
A: 复制 `flue_gas.db` 文件即可。
